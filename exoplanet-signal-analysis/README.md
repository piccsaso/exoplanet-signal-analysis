# Exoplanet Transit Signal Analysis

**Status: project scaffold. Analysis, application, and evaluation are not yet implemented.**

## Question
How reliably can a simple transit detector recover known or injected signals from telescope light curves?

## Planned tools
Python, NumPy, pandas, matplotlib, astronomy analysis tools

## Getting started
1. Install Python 3.11 or newer and Git.
2. Clone this repository and create an environment: `python -m venv .venv`.
3. On Windows, activate it with `.venv\Scripts\Activate.ps1`.
4. Follow `ROADMAP.md` in order. Add dependencies only as they are used.

There is no runnable analysis yet. No results or performance claims have been generated.
